# KisanFlow AI Development Rules

## Project Overview

KisanFlow is an AI-powered agriculture platform designed to help farmers
with useful, reliable and easy-to-understand agricultural information.

## Development Principles

- Keep the application simple, reliable and maintainable.
- Write clean, readable and well-structured code.
- Prefer reusable components over duplicated code.
- Do not introduce unnecessary dependencies.
- Keep secrets and API keys out of source code.
- Use environment variables for sensitive configuration.
- Validate user input.
- Handle errors gracefully.
- Do not break existing functionality when adding new features.

## Next.js Rules

- Use the App Router.
- Use TypeScript.
- Prefer server components where appropriate.
- Use client components only when client-side behavior is required.
- Keep components modular and reusable.

## UI Rules

- Build a responsive interface.
- Prioritize mobile usability.
- Keep the design clean and accessible.
- Use consistent spacing, typography and components.

## AI Rules

- AI responses should be useful, clear and understandable.
- Never expose API keys or private credentials.
- Handle AI/API failures gracefully.
- Do not present uncertain information as guaranteed fact.

## Git Rules

- Make small, meaningful commits.
- Use clear commit messages.
- Do not commit secrets, `.env` files or credentials.
- Test important changes before pushing.

## Before Completing Work

- Check for errors.
- Verify that the application still runs.
- Review changed files.
- Keep the implementation aligned with the project architecture.
